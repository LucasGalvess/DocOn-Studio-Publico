# DocOn Studio (página)

`index.html` é o código da página publicada no claude.ai:
https://claude.ai/artifact/SEU-STUDIO

Capacidades declaradas na publicação: `db` (projetos, estilos, banco, memória, histórico), `user` (escopo profile),
`sample` (Diretor), `assets` (upload: interact) e `downloads`.

Para atualizar: edite este arquivo e peça ao Claude para republicar no MESMO link (Artifact publish com `url`).
Os dados (projetos, estilos, bancos, memória) ficam no banco da página, não no repositório.
